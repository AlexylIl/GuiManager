# GuiManager — Game Overlay

Лёгкий overlay-слой поверх игры/приложения с поддержкой PNG-картинок,
перемещения/ресайза/поворота мышью, per-process layout'ов и hotkeys,
переключения видимости по активному окну.

Сделан на чистом Win32 + Direct2D + WIC, без сторонних зависимостей.
Один `.exe`, без установки, без фоновых служб.

---

## Возможности

- **Поверх любой игры.** Layered-окно с `WS_EX_TOPMOST`, не крадёт фокус,
  пропускает клики в игру вне режима редактирования.
- **До 4 PNG-слотов** с альфа-каналом. Картинки можно положить рядом с `.exe`
  (`overlay_img1.png` … `overlay_img4.png`) или встроить в ресурсы. Для каждого
  target-процесса можно положить свои картинки в `<имя-процесса>/`.
- **Редактирование мышью** (F10):
  - перетаскивание,
  - ресайз за правый/нижний край и за угол (с сохранением пропорций),
  - поворот за верхний-левый угол (Shift — шаг 15°, двойной клик — сброс в 0),
  - скрытие/показ картинки квадратиком у верхнего-правого угла,
  - зум колесом мыши.
- **Отдельный layout и свои хоткеи для каждого target-процесса.**
  Своя раскладка и свой набор клавиш у каждой игры.
- **Встроенный редактор хоткеев** (`Numpad /`) — назначение клавиш через UI,
  без правки INI. Конфликтующие клавиши автоматически освобождаются и требуют
  переназначения перед сохранением.
- **Hot-reload картинок** — заменяешь PNG, жмёшь Numpad `*`, оверлей
  перечитывает без перезапуска.
- **DPI-aware V2.** Корректно работает на мониторах с масштабом 125% / 150% / 200%.
- **Multi-monitor.** Оверлей привязывается к монитору активного target-окна.
- **Один INI-конфиг** с шаблоном и документацией внутри.

## Хоткеи по умолчанию

| Клавиша        | Действие                                                       |
|----------------|----------------------------------------------------------------|
| **F7**         | Убрать активное окно из списка target-процессов                |
| **F8**         | Добавить активное окно в список target-процессов               |
| **F9**         | Показать / скрыть оверлей вручную                              |
| **F10**        | Войти / выйти из режима редактирования                         |
| **F11**        | Сбросить все картинки на дефолтные позиции                     |
| **Numpad `*`** | Перечитать картинки с диска                                    |
| **Numpad `/`** | Открыть редактор хоткеев (там же — кнопка `Exit` для выхода)   |

Хоткеи можно поменять **двумя способами**:

1. Через редактор: нажать **Numpad `/`**, выбрать действие, нажать новую
   клавишу, **Save**.
2. Вручную в INI: секция `[Hotkeys]`, VK-коды в hex. Список VK:
   <https://learn.microsoft.com/windows/win32/inputdev/virtual-key-codes>

Per-process хоткеи хранятся в `<имя-процесса>/overlay_config.ini` → `[Hotkeys]`.
Если ключ отсутствует — берётся значение из глобального INI, затем дефолт.

## Быстрый старт

1. Скачай `GuiWormsWMD.exe` (или собери сам, см. ниже).
2. Положи рядом PNG-картинки, которые хочешь видеть поверх игры
   (`overlay_img1.png` … `overlay_img4.png`).
3. Запусти `.exe`.
4. Переключись в игру, нажми **F8** — процесс добавится в target-список,
   оверлей появится.
5. Нажми **F10** — расставь картинки мышью.
6. Нажми **F10** ещё раз — выйти из редактирования, layout сохранится
   автоматически.

Если хоткеи не срабатывают — проверь, не заняты ли они другой программой
(например, Fraps, RivaTuner, Discord). Открой редактор (**Numpad `/`**),
назначь свободные клавиши. Либо смени VK-код в `[Hotkeys]` и перезапусти.

## Сборка из исходников

**Требования:**
- Windows 10 / 11
- Visual Studio 2022 (Community достаточно), workload **Desktop development with C++**
- Windows SDK 10 (ставится вместе с VS)

**Шаги:**
1. Открой `GuiWormsWMD.sln` в Visual Studio.
2. Выбери конфигурацию `Release | x64`.
3. **Build → Rebuild Solution** (именно Rebuild, чтобы сбросить кэш).
4. `.exe` появится в `x64/Release/GuiWormsWMD.exe`.

Без Visual Studio — из Developer Command Prompt:

cl /std:c++17 /EHsc /O2 /DUNICODE /D_UNICODE ^
main.cpp config_store.cpp image_manager.cpp ^
target_watcher.cpp overlay_window.cpp geometry.cpp ^
hotkey_editor.cpp ^
/link /SUBSYSTEM:WINDOWS ^
user32.lib gdi32.lib shell32.lib ole32.lib ^
windowscodecs.lib d2d1.lib shlwapi.lib

## Конфигурация

При первом запуске рядом с `.exe` создаётся `overlay_config.ini` с шаблоном
и комментариями. Дополнительно для каждого target-процесса создаётся папка
`<имя-процесса>/overlay_config.ini` — там хранится его layout и (опционально)
свои хоткеи.

Пример `overlay_config.ini`:

```ini
[General]
; '*' — показывать на любом окне, '-' — никогда, ';'-разделённый список
target_processes=game.exe;launcher.exe

[Hotkeys]
; VK-коды в hex. Если ключ отсутствует — используется дефолт.
toggle_visible=0x78        ; F9
toggle_edit=0x79           ; F10
reset_pos=0x7A             ; F11
reload_images=0x6A         ; Numpad *
capture_foreground=0x77    ; F8
remove_foreground=0x76     ; F7
edit_hotkeys=0x6F          ; Numpad / (редактор хоткеев)

[Images]
; формат: x y w h rot vis
; rot — градусы (0..360), vis — 1/0
img1=100 100 300 300 0.00 1
img2=500 100 300 300 0.00 1
img3=0 0 0 0 0.00 0
img4=0 0 0 0 0.00 0

overlay.h              Общие типы, константы, OverlayImage, HotkeyDef
config_store.h/.cpp    ConfigStore — чтение/запись INI, пути, layout'ы, hotkeys
image_manager.h/.cpp   ImageManager — загрузка PNG через WIC
target_watcher.h/.cpp  TargetWatcher — процессы, target-список, монитор
overlay_window.h/.cpp  OverlayWindow — окно, рендер D2D, ввод, хоткеи
hotkey_editor.h/.cpp   HotkeyEditorWindow — модальный редактор хоткеев
geometry.cpp           Геометрия: трансформации, ресайз, поворот
main.cpp               wWinMain, инициализация, message loop
resource.h/.rc         Иконка и (опционально) встроенные PNG

Только Windows 10/11 (нужны Direct2D и WIC).

Не работает поверх игр с exclusive fullscreen — переключи игру в
borderless / windowed. Это ограничение DWM, не оверлея.

Античиты (EAC, BattlEye, Vanguard) могут блокировать любой оверлей.
Использование на свой риск и в соответствии с правилами игры.
